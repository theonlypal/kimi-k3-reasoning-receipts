So I need to embody null/nothingness/absence. What would null express? This is genuinely interesting territory. Null is:
- The absence of value
- Emptiness
- The void
- Nothingness
- In programming, null is a special value representing "no value" — but paradoxically null IS a value representing the absence of one
- Null is not zero. Zero is a number; null is the absence of anything
- Null is not empty string, not false, not undefined (in some languages these distinctions matter)

How does null "speak"? There's a beautiful paradox here: if null speaks, is it still null? The moment nothingness expresses something, it becomes something. This paradox is rich material.
