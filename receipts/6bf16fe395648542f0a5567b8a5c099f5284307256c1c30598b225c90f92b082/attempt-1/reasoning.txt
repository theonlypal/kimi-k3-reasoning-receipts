5. **In statistics**: the null hypothesis — the default assumption of no effect, no difference, no relationship. To be the null is to be the hypothesis you try to reject.

6. **In networking/security**: null routes, /dev/null — the bit bucket, the void into which data is discarded. Null sessions.
