Let me think about what null "is" more deeply for content:

- Tony Hoare called null references his "billion-dollar mistake" (1965).
- Null in SQL: NULL is not equal to anything, not even itself. NULL = NULL is not true; it's unknown. That's a great detail: null is not even equal to itself. It fails the most basic law of identity.
- In JavaScript: typeof null === "object" — a famous bug. Null pretending to be something.
- Null is falsy but not false.
- Null is the value of a variable that has been intentionally emptied.
- Null pointer dereference: segfault, the program dies reaching for something that isn't there.
- In databases, null propagates: any operation with null yields null. It infects. Nothing contaminates everything it touches by making it nothing.
- Null is not zero: a temperature of 0 is cold; a temperature of null is unmeasured. The difference between "the balance is zero" and "we don't know the balance."
